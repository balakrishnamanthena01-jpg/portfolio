# portfolio

Portfolio of **Balakrishna Manthena** — Full-Stack Developer.

A modern, high-performance developer portfolio featuring smooth page transitions, interactive floating project previews, magnetic magnetic interactions, and responsive design.

## 🚀 Built With

- **React 18** & **Vite**
- **React Router 6**
- **Lenis** (Smooth Scrolling)
- **Vanilla CSS** & Design System (Neue Montreal & Google Fonts)

## 🛠️ Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
